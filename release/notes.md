# codex-iq-watch-0.4.1

- 适配宿主 v3.29.7：宿主插件进程协议从 v4 升到 v5，旧版插件包在新宿主上无法加载；本版本 SDK 与打包 CLI 固定到 v3.29.7 发行标签，安装包按协议 v5 生成
- 适配 SDK 受管 HTTP 合同变化：请求／响应头改为二进制值，响应新增 `http_version` 与 `trailers`；Webhook／邮件通知行为不变
- 构建工具链升至 Rust 1.99.1（与宿主 SDK 的最低版本一致）
- 能力合同不变：observer v2、scheduler v3、management v2

需要宿主 `>=3.29.7, <4.0.0`，低于该版本的宿主无法安装本版本（v3.29.6 及更早的宿主请继续使用 0.4.0）。题库、模型测试与监控状态沿用 0.4.0，无需迁移

源码、进程集成测试已在 Linux 上通过，实际宿主升级和真实上游效果仍需安装后验证

安装包为 Linux x86_64，下载 `.tar.gz` 与对应 `.sha256` 校验文件
