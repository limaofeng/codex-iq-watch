# codex-iq-watch-0.3.0

- 新增可维护题库，支持新增、编辑、启用／停用和删除，内置糖果题与自行车 SVG 题
- 模型测试支持指定题目或随机抽取一道启用题目，保留账号、客户端 Key、模型与 reasoning effort 选择
- 规则题改用完整答案匹配，回答中仅出现正确数字不会被误判通过
- 人工题直接展示生成的 SVG 与原始回答，由调用者标记「正确」或「降智」，不要求评分或备注
- 每个账号保存最近一次测试及题目快照，支持重新查看与修改人工评价，并阻止旧评价覆盖新测试
- 测试与监控状态独立存储，测试结论不影响告警或账号调度；保留旧糖果题结果展示

需要宿主 `>=3.19.0, <4.0.0`。升级后从插件管理页进入「题库」和「模型测试」，旧测试记录没有保存题目快照或模型回答。清除账号记录也会清除该账号的最近测试，重置通知设置不会清空题库

本版提供规则判分与 SVG 人工判断，暂不包含 AI 判分和 HTML 网页交互预览。源码、进程集成及本地隔离页面检查已完成，实际宿主升级和真实上游效果仍需安装后验证

安装包为 Linux x86_64，下载 `.tar.gz` 与对应 `.sha256` 校验文件
