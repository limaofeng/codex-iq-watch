# codex-iq-watch-0.4.0

- 适配宿主 v3.29.1：SDK 固定到该发行标签，清单声明 observer v2、scheduler v3、management v2 的能力合同
- 账号调度改为只排除降智账号（`DelegateFiltered`），其余账号的选择与等待交给宿主原生调度；正常账号都在忙时由宿主排队等待，不再因插件指定了不可用账号而导致请求失败
- 候选账号全部降智时行为不变，仍按 `schedule_all_degraded` 回落（`delegate` 或 `reject`）
- 不再使用插件自带的挑号次序（in_flight、失败率、权重、账号 ID），选号完全遵循宿主智能调度设置

需要宿主 `>=3.29.1, <4.0.0`，低于该版本的宿主无法安装本版本。题库、模型测试与监控状态沿用 0.3.0，无需迁移

源码、进程集成测试已在 Linux 上通过，实际宿主升级和真实上游效果仍需安装后验证

安装包为 Linux x86_64，下载 `.tar.gz` 与对应 `.sha256` 校验文件
