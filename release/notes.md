# codex-iq-watch-0.4.2

- 适配宿主 v3.32.0：宿主插件进程协议从 v5 升到 v6，旧版插件包在新宿主上无法加载；本版本 SDK 与打包 CLI 固定到 v3.32.0 发行标签，安装包按协议 v6 生成
- 显式声明观察阶段的处理预算为 30 秒：v3.32.0 起各阶段按声明计时，观察阶段默认只有 2 秒，而告警在同一次观察调用内经宿主网络发送 Webhook／邮件，默认值会让外部接口经出站代理时来不及确认送达；调度沿用默认 2 秒，管理页（含模型测试）沿用默认 120 秒
- 适配 SDK 合同变化：`RequestCompleted` 移除 `response_model`，插件未使用该字段，仅同步测试数据
- 能力合同不变：observer v2、scheduler v3、management v2

需要宿主 `>=3.32.0, <4.0.0`，低于该版本的宿主无法安装本版本（v3.31.x 及更早的宿主请继续使用 0.4.1）。题库、模型测试与监控状态沿用 0.4.1，无需迁移

源码、进程集成测试已在 Linux 上通过，实际宿主升级和真实上游效果仍需安装后验证

安装包为 Linux x86_64，下载 `.tar.gz` 与对应 `.sha256` 校验文件
